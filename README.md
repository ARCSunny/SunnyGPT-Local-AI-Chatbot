# SunnyGPT-Local-AI-Chatbot
SunnyGPT is a ChatGPT-inspired conversational AI application built with Python, Streamlit, and Ollama. It provides a clean chat interface where users can communicate with a locally running large language model (LLM), maintain multiple conversations, switch between light and dark themes, and store chat history in a JSON file.
## 📸 Project Overview

SunnyGPT offers a simple, modern conversational interface with:

- A ChatGPT-style layout
- A sidebar containing previous conversations
- Creation of new chats
- Persistent chat history
- Automatic chat titles
- Streaming AI responses
- Light and dark themes
- A locally hosted Gemma 3 4B language model
- A JSON-based storage system

## ✨ Features

### 1. AI-powered conversations

Users can enter questions or prompts and receive responses generated by the Gemma 3 4B model through Ollama.

The application sends the conversation history to Ollama and displays the model's response in the chat interface.

### 2. Streaming responses

AI responses are displayed progressively rather than appearing all at once.

This creates a more natural conversational experience and makes the application feel more responsive.

### 3. Multiple chat sessions

Users can create separate conversations using the New chat button.

Each conversation has its own:

- Chat ID
- Title
- Message history
- Creation timestamp
- Last-updated timestamp

### 4. Persistent chat history

Chat data is stored locally in chats.json.

This means conversations can remain available after the Streamlit application is restarted, provided that the JSON file is preserved.

### 5. Automatic chat titles

When a new conversation receives its first user message, SunnyGPT automatically creates a title from that message.

Long titles are shortened to keep the sidebar organized.

### 6. Delete conversations

Users can delete individual conversations from the sidebar.

The application includes a confirmation step before permanently removing a chat from the local JSON store.

### 7. Light and dark themes

Users can switch between:

- Dark mode
- Light mode

The interface uses custom CSS to style the main application area, sidebar, chat input, buttons, borders, and text.

### 8. Responsive Streamlit interface

The application uses Streamlit components such as:

- st.sidebar
- st.chat_message
- st.chat_input
- st.button
- st.columns
- st.session_state

These components make the application usable in a browser without building a separate frontend framework.

## 📁 Project Structure
```
AI-CHATBOT/
│
├── app.py
├── memory.py

├── requirements.txt
└── README.md
```
### app.py

The main Streamlit application.

It is responsible for:

- Configuring the page
- Managing the interface theme
- Rendering the sidebar
- Displaying chat messages
- Accepting user prompts
- Sending conversation history to Ollama
- Streaming AI responses
- Creating, switching, and deleting chats

### memory.py

Contains the ChatStore class, which manages chat persistence.

The class provides methods for:

- Loading chat data
- Saving chat data
- Creating chats
- Retrieving chats
- Listing all chats
- Adding messages
- Renaming chats
- Deleting chats
- Checking whether a chat is empty
